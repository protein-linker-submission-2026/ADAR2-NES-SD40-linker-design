# Results directory

- `results.xlsx`: complete reader-facing workbook.
- `results.csv`: standardized formal-candidate list generated by `predict.py`.
- `all_candidate_records.csv`: all candidate-level records, including candidates that did not reach final ranking.
- `all_model_records.csv`: all 588 model-level records.
- `top_candidates_above_baseline.csv`: the 22 candidates scoring strictly above the GGGGSGGGGS baseline.
- `span_summary.csv`: per-span funnel summary.
- `report.pdf`: journal-style grayscale report.
- `figures/`: grayscale main figures.
- `structures/rfdiffusion/`: all production RFdiffusion backbone PDB files.
- `structures/boltz2/`: all 588 final Boltz-2 PDB structures, retained under span/candidate directories.
- `rmsd/`: linker RMSD gate outputs.
- `docking/`: Vina gate records and supporting docking outputs included in the analysis.

The main cross-distance comparison uses only the online MMseqs2 11-20 A batch. The earlier 16 A single-sequence-MSA batch is retained as a sensitivity comparison and is labeled separately.
