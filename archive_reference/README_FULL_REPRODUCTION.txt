ADAR2-NES-SD40 full reproduction archive

This directory contains the complete non-duplicate contents of the anonymized
scientific archive, split into GitHub Release assets below 2 GiB each.

Download all 11 ZIP files plus FULL_REPRODUCTION_SHA256SUMS.txt. Verify every
SHA256 value, then extract every ZIP into the same empty directory. Directory
names shared by multiple volumes are expected and reconstruct one archive tree.

The archive includes all 11-20 A online-MSA production records, the earlier
16 A single-sequence-MSA batch, public references, methods, run logs, manifests,
MSA files, prediction arrays, RFdiffusion outputs, ProteinMPNN outputs, Boltz-2
outputs, RMSD gates, docking records, ranker records, result workbooks, and
file-level provenance.

It intentionally excludes third-party pretrained weights, Conda environments,
software caches, duplicate archives, private competition documents, and
identity-bearing source files, as documented in README_提交说明.md and
匿名化报告.json.
